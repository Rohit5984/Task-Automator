# 🚀 Task Automator

A lightweight Windows automation tool designed to simplify repetitive tasks and help you get your workspace ready in seconds.

## ✨ Features

* **📦 Install Multiple Apps** — Install multiple applications quickly.
* **🌐 Open Multiple URLs** — Launch multiple websites simultaneously.
* **⚡ Automate Tasks** — Save time by automating repetitive actions.
* **🛠️ Simple & Easy to Use** — Designed with a straightforward interface.
